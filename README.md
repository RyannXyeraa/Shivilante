Shivilante

Shivilante is a Minecraft mod built with Fabric that aims to expand the gameplay experience with new items, tools, and other features.

«🚧 Status: Work in progress. More features are planned for future releases.»

Features

- 🧰 New items and tools
- ⚔️ Additional gameplay possibilities
- 🧩 Built using the Fabric modding ecosystem
- 🌱 Designed to grow with future updates

Features listed above describe the project's goals. Availability may change as development progresses.

Requirements

- Minecraft version: See "gradle.properties"
- Fabric Loader: Compatible version for the target Minecraft release
- Fabric API: If required by the project configuration

Installation

1. Install Minecraft Java Edition.
2. Install Fabric Loader for the Minecraft version supported by Shivilante.
3. Download the Shivilante mod JAR from a project release.
4. Place the JAR file in your Minecraft "mods" folder.
5. Install any required dependencies and launch the game.

Note: Development builds may not be ready for normal gameplay. Check the release notes before installing.

Building from Source

Make sure you have a compatible Java Development Kit (JDK) installed.

Clone the repository:

git clone https://github.com/RyannXyeraa/Shivilante.git
cd Shivilante

Build the mod using the Gradle wrapper:

./gradlew build

The resulting JAR files are generated in:

build/libs/

Use the appropriate remapped JAR for installation.
